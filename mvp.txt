## Extension Specification: Articulate Storyline Animation & Audio Bypass

**Context**
The target site uses an Articulate Storyline player embedded via an `iframe`. The tutorial flow is gated by audio duration; even when manually skipping audio, UI components (buttons/animations) remain hidden until the original audio duration has elapsed.

**Diagnostics**
The tutorial engine manages state through a custom internal timeline rather than standard HTML5 media events. Key technical findings include:

| Component | Technical Detail |
| :--- | :--- |
| **Framework** | Articulate Storyline (Modern/HTML5 Output) |
| **Media Container** | `iframe` containing multiple `<audio>` elements (Base64 and `.mp3`) |
| **State Management** | Global `window.DS` and `window.globals` objects inside the iframe |
| **Visibility Logic** | Uses a `.hidden` class which applies `display: none` |
| **Element Classes** | `.slide-object`, `.shown`, `.hidden`, `.slide-object-vectorshape` |

**Actionable Findings**
* **CSS Override:** The player toggles the `.hidden` class to control the tutorial flow. Forcing these elements to display via CSS will bypass visual gates.
* **Volume Control:** Audio can be silenced by targeting all `<audio>` and `<video>` elements within the iframe context.
* **Timeline Logic:** The engine relies on `window.DS` for connection and asset loading. Forcing the `display` property is more reliable than attempting to manipulate the proprietary `DS` timeline object.
